# Coffee Sales Dashboard

An interactive Microsoft Excel dashboard for analyzing coffee sales performance across products, coffee types, customers, countries, and time periods.

## 📌 Project Overview

This project demonstrates how Excel can be used to transform raw sales transaction data into an interactive business analytics dashboard.

The workbook combines order-level data, customer information, product information, Pivot Tables, lookup-based data integration, and dashboard reporting.

## 🎯 Project Objectives

* Analyze coffee sales performance
* Identify sales trends over time
* Compare coffee product types
* Analyze customer and geographic information
* Evaluate product profitability
* Summarize sales using Pivot Tables
* Build an interactive Excel dashboard for business decision-making

## 📊 Workbook Structure

| Worksheet   | Description                                |
| ----------- | ------------------------------------------ |
| `Dashboard` | Main interactive sales analytics dashboard |
| `Pivots`    | Pivot-based sales analysis                 |
| `Orders`    | Order-level transactional data             |
| `Customers` | Customer master data                       |
| `Products`  | Product and pricing information            |

## 🔄 Data Integration

Customer and product information are connected to the order-level dataset using Excel lookup formulas.

For example, customer information is retrieved from the `Customers` worksheet using the Customer ID, while product information is retrieved from the `Products` worksheet using the Product ID.

This creates a more structured analytical dataset from multiple source tables.
